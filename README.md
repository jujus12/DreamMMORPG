# DreamMMORPG

Android için MMORPG projesi (Knight Online tarzı oynanış: tıkla veya WASD ile yürü).

## Şu an neler var (v0.1)

- Karakter seçme ekranı (4 slot, cihazda saklanır)
- Karakter oluşturma: **Warlord** (savaşçı), **Runeseer** (destek), **Assassin** (ninja), **Mage** (büyücü)
- Huzur Ormanı – Başlangıç Köyü: ortada ulu ağaç, meydan, han, demirci, depo, pazar, görev panosu, köy kapısı
- NPC'ler (konuşmak için dokun veya `E`)
- Hareket: ekrana dokun (basılı tut) veya `WASD` / ok tuşları

Yetenekler (1-5) henüz yok.

## APK nasıl alınır

1. GitHub'da **Actions** sekmesinde "Build APK" çalışır (her `main` push'unda otomatik).
2. Bittikten sonra **Releases** bölümünden `DreamMMORPG.apk` dosyasını indirip kur.

Kodlar: `app/src/main/java/com/dreammmorpg/game/`
